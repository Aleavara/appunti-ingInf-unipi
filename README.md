# Archivio Appunti Ingegneria Informatica - Università di Pisa
Il presente repository ospita una raccolta organizzata di materiale didattico e appunti relativi al corso di laurea in Ingegneria Informatica presso l'Università di Pisa. L'obiettivo del progetto è la creazione di un archivio centralizzato, strutturato e cronologico per supportare lo studio individuale e la preparazione degli esami.

Organizzazione dei contenuti
La struttura del repository è suddivisa per anno accademico e per insegnamento, al fine di garantire una navigazione intuitiva:
.
├── primoAnno/          # Materiale relativo al primo anno di corso
│   ├── analisi1/       # Analisi Matematica I
│   └── [altre materie]
├── secondoAnno/        # Materiale relativo al secondo anno di corso
└── terzoAnno/          # Materiale relativo al terzo anno di corso
All'interno di ogni materia, i contenuti sono ulteriormente ripartiti tra appunti delle lezioni frontali, schemi riassuntivi ed esercitazioni.

È possibile clonare l'intero repository tramite il comando:
git clone https://github.com/Aleavara/appunti-ingInf-unipi.git

Collaborazione
Il repository è aperto a contributi da parte di altri studenti. Per aggiungere materiale o segnalare correzioni:
Effettuare il fork del repository.
Caricare i file rispettando la struttura delle directory e la nomenclatura stabilita.
Inviare una Pull Request descrivendo brevemente le modifiche apportate.
Note legali e clausole di esclusione della responsabilità
Il materiale qui contenuto rappresenta una rielaborazione personale e non sostituisce in alcun modo i testi ufficiali o le lezioni dei docenti. L'autore non garantisce l'assenza di errori o l'esaustività degli argomenti trattati. L'utilizzo di tali materiali è a discrezione dell'utente.
